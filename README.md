# Dungeon Escape

Dungeon Escape is a polished console-based dungeon adventure game. Venture into a dark dungeon, face monsters, avoid traps, collect treasure, and try to escape alive! The game features multiple difficulty settings and colorful console output for an engaging experience.

## Features

- Turn-based dungeon adventure gameplay
- Randomized rooms and events (monsters, traps, treasure, potions, magic weapons)
- Multiple difficulty levels: Easy, Normal, Hard
- Colorful and styled console output
- Replayable with different outcomes each run
